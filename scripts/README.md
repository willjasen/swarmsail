# Swarmsail scripts

- `provision_subscriber.py` — Reserve a dedicated managed Headscale instance for an opaque Rawrarr account after an operator has verified an active trial or subscription. Run `python3 -m scripts.provision_subscriber --help`. It reads an existing `instances.json`, previews by default, and requires `--apply` to write the config and local Swarmsail SQLite mapping. Add `--new-private` only when the active tailnet is shared and the owner is creating a new private generation. It does not deploy the instance or configure DNS/ingress.
- `issue_lan_certificate.sh` — Preview or issue/renew a trusted certificate for `rawrarr.willjasen.net` through lego and Cloudflare DNS-01. Requires Docker and a mode-600 token at `~/Library/Application Support/Swarmsail/cloudflare-dns-token`; use `--apply` to change ACME/DNS state. It never prints the token.

The existing root-level `manage_headscale.py` generates managed Compose and Headscale config files. When `caddy.enabled` is true, it also generates a Caddy DNS-01 reverse proxy for each managed Headscale `server_url`; its Cloudflare token stays in a node-local read-only secret file. `python3 manage_headscale.py generate --config <path>` previews; add `--apply` only after reviewing the target. The Swarmsail web process also imports its config loader and generator.
