# Script tests

- `test_provision_subscriber.py` checks dry-run behavior, active eligibility, idempotent reservation, preservation of adopted instances, stable account network settings, and multiple independent active tailnets per account. Run `python3 -m unittest discover -s scripts/tests -v` from the repository root. Fixtures use temporary JSON and SQLite files only.
- `test_manager_caddy.py` checks generated Caddy ingress ports, droplet public IPv4 validation, secret-file references, Headscale and external-service hostname routes, explicit external-network scoping, and rejects conflicting NPM ingress, public Headscale listeners, missing network declarations, and duplicate hostnames. Run with `python3 -m unittest scripts.tests.test_manager_caddy -v` or the full scripts test command.
- `test_verify_droplet_ipv4.py` verifies the configured droplet IPv4 against provider metadata and direct DNS results using injected test data. Run with `python3 -m unittest scripts.tests.test_verify_droplet_ipv4 -v`.
- `test_health_page.py` checks the browser-facing Swarmsail health page is branded HTML with a rendered check time. Run with `python3 -m unittest scripts.tests.test_health_page -v` or the full scripts test command.
- `test_full_stack.py` is an opt-in Docker integration test that deploys Swarmsail, Headscale, Caddy, CrowdSec, and two Tailscale clients. It checks trusted HTTPS, managed-instance inventory, enrollment, bidirectional overlay ICMP/TCP, and CrowdSec log parsing. Run `SWARMSAIL_RUN_E2E=1 python3 -m unittest scripts.tests.test_full_stack -v`; ordinary discovery skips it. See [the runbook](../../runbooks/test-full-stack.md) for prerequisites and cleanup.
